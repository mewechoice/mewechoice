# Como cadastrar um artigo da MWeC (sem programar)

## Fluxo simples

1. Abra **GitHub → Issues → New issue → Novo artigo para o Explore**.
2. Digite título, categoria, resumo, texto e fontes. Clique em **Submit**.
3. O conteúdo fica como **rascunho em revisão**; não é automaticamente exibido no site.
4. Envie o link da Issue no chat da MWeC para revisão e preparação do artigo.
5. O Owner analisa o texto, as fontes e os resultados dos testes. Só após aprovação expressa ocorre publicação na biblioteca.

Formulário: https://github.com/mewechoice/mewechoice/issues/new?template=novo-artigo.yml

## Preservação de governança
Os quatro artigos legados em `LEARNING` permanecem bloqueados. A criação de Issue jamais altera o status editorial. Não existe auto-publicação de Issues ou comentários. Revisão de fontes, conhecimentos e regras regulatórias continuam obrigatórias. O cadastro sem programação já está disponível no GitHub; um painel de edição dentro do próprio site é uma expansão futura, que requer autenticação, banco de dados e permissões.
